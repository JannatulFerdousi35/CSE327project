# Community Action Bridge — Bangladesh-Focused UI/UX Prompt

Redesign the existing **Community Action Bridge** prototype specifically for users in **Bangladesh**.

The platform connects local residents, volunteers, and administrators to identify and solve community problems. The main target users are people living in **Bangladeshi districts, upazilas, unions, villages, and urban neighborhoods**.

The design must feel like a **real Bangladesh community service platform**, not a generic international application.

Prioritize:

* Simple language
* Easy navigation
* Mobile-first usability
* Low-bandwidth awareness
* Familiar Bangladesh locations and terminology
* Clear community-focused actions
* Bengali-friendly interface
* Realistic Bangladeshi examples

---

# 1. Bangladesh-Specific Location System

Use Bangladesh's location structure throughout the application.

For registration and reporting, provide:

**Division → District → Upazila → Union/Ward → Village/Area**

Example:

Division: Dhaka
District: Tangail
Upazila: Mirzapur
Union: Jamurki
Village: Jamurki

Use dropdowns instead of requiring users to type locations manually.

Allow users to change their location from their profile.

# 2. Language and Text

Design the interface primarily in **simple English**, but make the UI ready for **Bangla localization**.

Use familiar Bangladeshi terms such as:

* District
* Upazila
* Union
* Ward
* Village
* Community
* Volunteer

Include a visible:

**English | বাংলা**

language switcher.

Use Bengali examples in selected areas to demonstrate localization.

For example:

"আপনার এলাকার সমস্যা রিপোর্ট করুন"

"কমিউনিটির জন্য স্বেচ্ছাসেবক হোন"

Do not translate every page into Bengali automatically; instead, make the interface clearly ready for bilingual support.

# 9. AI Suggestions

Do not make the AI page a generic chatbot.

Make it an **AI Community Action Planner**.

Example:

### Problem

"Waterlogging on the road near Jamurki Primary School."

AI analyzes the problem and provides:

### Suggested Action Plan

**1. Identify the blocked drainage points**

**2. Organize 8–10 volunteers**

**3. Arrange shovels, gloves, and waste bags**

**4. Clean the blocked drainage**

**5. Monitor the road after rainfall**

### Estimated Requirements

Volunteers: 8–10

Estimated time: 1–2 days

Materials:

* Shovels
* Gloves
* Waste bags

Estimated budget:

**৳3,000–৳5,000**

Use the **৳ Bangladeshi Taka symbol** instead of dollars.

Clearly label AI-generated estimates as suggestions, not guaranteed costs.

# 14. Low-Bandwidth Friendly Design

Because some users may use slower mobile networks:

* Keep pages lightweight
* Avoid unnecessary animations
* Use compressed images
* Avoid large background videos
* Use simple icons
* Use clear loading indicators
* Show useful information even if images are still loading
* Keep forms simple

---

# 15. Bangladesh Visual Identity

Use subtle Bangladesh-inspired visual elements without making the interface overly decorative.

Use:

* Green as the primary color
* Red only for important warnings/emergency states
* White/light backgrounds
* Subtle Bangladesh map illustrations where appropriate
* Images showing Bangladeshi communities
* Rural roads
* Villages
* Schools
* Tube wells
* Local volunteers
* Community activities

Do NOT make every screen look like a Bangladesh flag.

Keep the overall interface modern and professional.

---

# 16. User-Friendly Design Rules

The first-time user should understand the application within a few seconds.

Every page should have:

* One clear primary action
* Short labels
* Large buttons
* Simple icons
* Clear status indicators
* Easy-to-read cards
* Minimal unnecessary information

Avoid:

* Complicated dashboards for normal users
* Too many statistics
* Long forms
* Technical terminology
* Tiny buttons
* Excessive charts
* Excessive animations

---

# Final Goal

Make **Community Action Bridge** look like a realistic Bangladesh-focused community platform that could actually be used by residents and volunteers.

The design should communicate:

**"See a problem → Report it → Community confirms it → Volunteers join → AI helps plan → Community solves it."**

Maintain all existing pages:

1. Login
2. Home
3. Report Issue
4. Issue Details
5. Volunteer Dashboard
6. Event Dashboard
7. AI Suggestions
8. Profile
9. Admin Dashboard

Improve the existing prototype rather than removing its main functionality.
